# CoozyGames Payments — الاشتراك الشهري (Manual Payments)

- **التاريخ:** 2026-09-23
- **الحالة:** MVP — خطة شهرية واحدة، دفع يدوي برفع إيصال، تأكيد من الداشبورد، وقفل اللعب.
- **النطاق:** نفس تطبيق Next.js الموجود (لا توجد بوابة دفع خارجية).

## الهدف

نظام يشتراك شهري واحد: المستخدم يختار طريقة دفع يدوية (فودافون كاش / إنستاباي)،
يدفع ويرفع صورة الإيصال مع رقم العملية، والأدمن يرجّع/يرفض من لوحة التحكم.
لما الاشتراك يكون **فاعل** المستخدم يقدر يلعب؛ والعرض/التصفح يفضل 100% متاح للجميع.

## القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| عدد الخطط | خطة واحدة: **شهرية** فقط | مطلوب في هذه المرحلة |
| السعر | من الداشبورد عبر `app_settings` → `PREMIUM_MONTHLY_PRICE` (fallback: 100) | يُعدّل بدون كود |
| طرق الدفع المبدئية | **فودافون كاش + إنستاباي** (seed) | اختيارك |
| إثبات الدفع | صورة إيصال + رقم العملية + اسم المُرسِل (كلها إجبارية) | التحقق الأدمني |
| تخزين الإيصال | `bytea` داخل `payments.receipt_image` بعد ضغط بـ `sharp` | لا توجد mount للقرص ولا dependency جديدة |
| تمديد المدة | `expires_at = greatest(آخر اشتراك فاعل, الآن) + 30 يوم` | التجديد ما يبطلش الأيام الباقية |
| حالة الاشتراك | محسوبة: فاعل إذا `expires_at > now()` — بدون cron | صفر عمليات خارج الطلب |
| Gating اللعب | سيرفر-سايد في `app/play/[slug]/page.tsx` (نقطة وحدة) | كل الألعاب بتعدّي منه |
| العملة | جنيه مصري `EGP` (عرض `ج.م`) | ثابتة في هذا الـ MVP |
| واجهة الشراء | صفحة عامة `/premium` + لينك من `/profile` والهيدر | سهلة الوصول |

## الوحدات

1. **صفحة المستخدم `/premium`** — السعر، طرق الدفع، رفع الإيصال، حالة الاشتراك، سجل الدفعات.
2. **الداشبورد `/dashboard/billing`** — طلبات معلّقة/موافقة/رفض + إيصال + سعر الخطة + إدارة طرق الدفع.
3. **Gating اللعب** — شاشة "الاشتراك مطلوب" بدل تشغيل اللعبة.

## خارج النطاق (حاليًا)

- أكثر من خطة (شهر/سنة) — يخصّ لهذه المرحلة خطة شهرية واحدة.
- بوابة دفع إلكترونية (Stripe/Card/Paymob...) — يدوي بالكامل.
- إشعار التفعيل بالبريد أو SMS عند الموافقة/الرفض.
- تذكير انتهاء الاشتراك (email/notification).
- قفل وصول خلف بريميوم لأكثر من اللعب (مزايا العروض/التقييمات...).

## مراجع سريعة

- الـ auth: `lib/auth.ts`, `lib/dashboard/admin.ts` (`requireAdmin`)
- الإعدادات الديناميكية: `lib/dashboard/settings.ts` (`getSetting`), `app_settings` table
- الضغط: `sharp` (موجود بالفعل في dependencies)
- التصميم العام (ثيم ليلي): tokens `night-*` / `mist-*` في `app/globals.css`
- التصميم الداشبورد (ثيم فاتح): مكونات shadcn `@/components/ui`
- تشغيل اللعبة: `app/play/[slug]/page.tsx` → `components/game-stage.tsx`
