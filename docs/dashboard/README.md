# CoozyGames Dashboard — خطة التنفيذ

- **التاريخ:** 2026-09-23
- **الحالة:** Phase 1 + Phase 2 + Phase 3 الأساسية منفّذة (health + ops + purge);
  المتبقّي من Phase 3 اختيارات مؤجّلة (انظر `roadmap.md`).
- **النطاق:** لوحة إدارة داخل نفس تطبيق Next.js الموجود.

## الهدف

لوحة إدارة (Dashboard) للتحكم في موقع CoozyGames: عرض الإحصائيات، إدارة المستخدمين،
التحكم في الألعاب (تمييز/إخفاء/ترتيب)، وتتبّع اللعب الحقيقي، ومراقبة تشغيل السيرفر
(كاش الصور + حالة Wisp).

## القرارات المعتمدة

| القرار | الاختيار | السبب |
|---|---|---|
| النطاق | نظرة عامة + إحصائيات، إدارة المستخدمين، إدارة الألعاب، مراقبة التشغيل | مطلوب في أول نسخة |
| مصدر الكتالوج | `data/games.json` يفضل مصدر الحقيقة للعامة + **`game_overrides` في Postgres** | تغيير أصغر، ويحل مشكلة أن الملف على قرص مؤقت في الإنتاج |
| الأدوار | **better-auth admin plugin** (`role` / `banned` / user management) | جاهز ومتكامل مع الـ auth الحالي |
| تتبع اللعب | **`play_events`** فعلي | الإحصائيات الحالية (`pseudoStats`) وهمية |
| مسار الداشبورد | `/dashboard` | افتراضي مقترح |
| الـ migrations | runner بسيط `db/migrations/*.sql` + `scripts/migrate.mjs` | بدون dependencies جديدة، ويخدم كل الجداول الجديدة |
| الاستضافة | داخل نفس تطبيق Next | يتوافق مع `deploy/` الحالي |

## الوحدات

1. **نظرة عامة** — عدّادات ورسوم بسيطة (ألعاب/مستخدمين/جلسات/لعب/حجم الكاش).
2. **المستخدمون** — عرض/بحث/ترقيم، حظر/فك حظر، تغيير دور، إنهاء جلسات، حذف.
3. **الألعاب** — عرض الكتالوج (من JSON) + إدارة overrides (إخفاء/تمييز/ترتيب/عنوان عربي/صورة).
4. **التحليلات** — لعب فعلي: إجماليات، أشهر الألعاب/التصنيفات، توزيع زمني.
5. **التشغيل** — حجم/عدد ملفات `image-cache/`، تنظيف الكاش، حالة سيرفر Wisp، عدّادات DB.

## مراجع سريعة للمشروع

- الـ auth: `lib/auth.ts`, `lib/auth-client.ts`, `lib/db.ts`, `lib/profile.ts`
- الـ middleware: `proxy.ts` (matcher يغطّي كل المسارات ما عدا `api/_next/favicon`)
- الكتالوج: `data/games.json`, `lib/games.ts`, `lib/categories.ts`
- الصور: `app/image/[...path]/route.ts` + `image-cache/`
- البروكسي: `proxy-server/server.mjs`, `lib/proxy.ts`, `components/game-stage.tsx`
- النشر: `deploy/` + `docs/performance/`
